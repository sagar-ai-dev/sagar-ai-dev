### ⭐ Featured: my MSc thesis

**[Causal Anomaly Detection from Multivariate Time Series](https://github.com/sagar-ai-dev/Causal-Anomaly-Detection-from-Multivariate-Time-Series)**, supervised by Prof. Daniele Meli

Some faults hide inside normal ranges: every sensor looks fine, but the relationship between sensors has changed. I learned causal graphs from healthy data, tracked the regression coefficients along those links with recursive least squares, and raised an alarm when they drifted.

- **27 configurations** under one fair pipeline: 3 causal discovery algorithms (PCMCI, GES, CAM-UV) × 3 regression models × 3 real domains: a SoftBank Pepper robot (244 sensors), 12-lead ECG (PTB-XL) and the Tennessee Eastman chemical process
- **0.81 vs 0.71 AUC-ROC on ECG**: causal detection beat the best tuned neural network (LSTM, TCN, Transformer autoencoders)
- **Explanations that name the cause**: on a robot attack, 9 of 9 configurations named the documented sensor, which had moved only 78th most
- **The honest answer is "when", not "whether"**: where a simple baseline already catches the faults, structure adds little. Where it fails, causal structure helps most
